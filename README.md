# AUREN-KA-V2-Mobile-
AUREN KA v2.0 es un asistente personal inspirado en JARVIS, con voz y texto, activación por palabra clave, voz grave y robótica, accesos a aplicaciones e integración prevista con Gemini AI. En desarrollo para Android y Windows 11, busca ofrecer conversaciones inteligentes, perfiles personalizados y reconocimiento seguro de su creador, Kaze.
